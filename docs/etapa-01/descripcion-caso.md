# Descripción del Caso

El presente trabajo se enmarca en el rubro de venta de componentes de computadora, un sector comercial dedicado a la comercialización de:

* **Hardware:** Placas madre, procesadores, memorias RAM, unidades de almacenamiento, placas de video, fuentes de alimentación, gabinetes y sistemas de refrigeración.
* **Periféricos:** Teclados, mouses, monitores, auriculares, webcams y parlantes.
* **Accesorios:** Cables, adaptadores, soportes, hubs USB y pads, entre otros.
  
## Problemática Actual

Actualmente, gran parte de los comercios de este rubro administran su stock, sus clientes y sus ventas mediante planillas de cálculo o sistemas básicos que no permiten un control centralizado ni actualizado en tiempo real. 

Esta situación genera inconvenientes habituales tales como:

- Discrepancias entre el stock físico y el registrado.
- Dificultad para llevar un historial ordenado de compras por cliente.
- Errores en el cálculo del importe de ventas ya concretadas cuando el precio de un producto se modifica con posterioridad a la operación, dado que muchos sistemas no conservan el precio vigente al momento exacto de cada venta.
